STUDYSONIC V9.0 — FLAT MOBILE RELEASE

CONTENTS
- index.html — Version Hub; V7 and V8 remain available, V9 is current
- style.css — Version Hub styling
- v7.html / v7.css / v7.js — preserved V7
- v8.html / v8.css / v8.js — preserved V8
- v9.html / v9.css / v9.js — new V9 release

V9 CHANGES
- Proper mindmap opening animation: canvas bloom, curved branch draw-on, and staggered node entrance
- Retains V8 features, including device choice, set creation, practice auto-advance, mindmap editing, pinch zoom and exports
- Uses the existing V8 mindmap local-storage key so maps already saved in V8 remain visible in V9 on the same browser/device

INSTALLATION
1. Extract this ZIP. All files are at the ZIP root (no folders).
2. Upload the extracted files to the ROOT of your existing GitHub Pages repository.
3. Replace index.html and style.css; add the V9 files; keep/replace the included V7 and V8 files.
4. Keep all existing V1–V6 files in your repository. They are not included in this package.
5. Do not upload the ZIP itself as a website file; extract it first.

NOTE
The archive, file links, local asset references and JavaScript syntax were checked. Actual GitHub Pages deployment and live browser interaction are not testable from this package build alone.
