StudySonic V1 — main release package

Main application files: v10.html, v10.css, v10.js.
The Version Hub labels this application as V1.
Older releases are archived as V0.1 through V0.9 and remain individually launchable.
V0.5 and V0.6 retain their glitch warnings.

Install: extract and merge into the repository root. Keep existing folders and files.
Do not delete older version folders. Replace index.html/style.css only when deploying this flat-root package.

The V1 application is based directly on the working V0.9 application code. Its local storage keys are retained to preserve existing study sets and mindmaps on the same browser/device.
