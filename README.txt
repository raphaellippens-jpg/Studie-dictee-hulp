STUDYSONIC V8.0 — FLAT MOBILE PACKAGE

CONTENTS
- index.html — Version Hub, updated to list V8
- style.css — Version Hub styling
- v8.html — V8 application
- v8.css — V8 application styling
- v8.js — V8 application logic

INSTALLATION
1. Extract this ZIP. All files are at the ZIP root.
2. Upload these files to the ROOT of your existing GitHub Pages repository.
3. Replace index.html and style.css, and add/replace v8.html, v8.css and v8.js.
4. Keep all existing v1-v6 files in the repository. They are intentionally NOT included in this package.

The Version Hub keeps links to older versions; those pages continue to work from the files already in your repository.
