STUDYSONIC V1 — RELEASE PACKAGE

This is the new V1 launcher and main application.

INSTALLATION
1. Extract every file in this ZIP.
2. Upload the extracted contents to the repository root.
3. Replace index.html, style.css and hub.js with these V1 launcher files.
4. Keep all files together at the repository root. Do not upload the ZIP itself.

VERSION ARCHIVE
The launcher displays V0.1 through V0.9 in chronological order. V0.5 and V0.6 are marked with red glitch warnings. The historical version files are included as separate v1…v9 HTML/CSS/JS files. The new main V1 app is app.html/app.css/app.js.

DATA
The main app retains the existing StudySonic IndexedDB database and mindmap localStorage keys so locally saved sets and mindmaps on the same browser/device remain accessible.

NOTE
The ZIP includes the historical version-specific source files and the V1 app. It does not contain the older index.html/style.css files from each historical archive because those are replaced by the new V1 launcher.
