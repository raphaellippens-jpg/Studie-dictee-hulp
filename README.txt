V5 FEATURES
- Start popup: Robot voice or My own voice. You can go back and change modes.
- Robot voice mode builds sets from typed lists using the selected language and available device voice.
- My own voice mode queues a typed list and records each word one at a time.
- Auto-advance after typing: an exact correct answer triggers a 1.5-second countdown, then the next word plays automatically.
- The same answer input element is reused and focused between questions to help keep the iPad keyboard open.
- Hands-free playback remains a separate toggle for the existing submit-based workflow.
- Interface translations: English, Dutch, French and Spanish.

NOTES
- Microphone recording requires HTTPS (GitHub Pages works) and browser permission.
- Audio recordings and sets remain stored locally in this browser/device using IndexedDB.
- Browser text-to-speech voices depend on the voices installed on the device.
- Import/export uses the existing StudySonic set format. V5 keeps compatibility with V4 sets.
