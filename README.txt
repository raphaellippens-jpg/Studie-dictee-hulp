StudySonic V11 package — public release V1.1

This flat archive contains the new V1.1 application (v11.html, v11.css, v11.js), the major-version chooser, V1 and V2 archive pages, and all previous V0.1–V0.9 application files.

Version mapping:
- V1 archive launches the released V1 app at v10.html.
- V0.1–V0.9 launch their historical files v1.html through v9.html.
- V2 archive lists V1.1 as available and launches v11.html. V1.2–V1.9 and V2 are vacant future slots.

V1.1 additions:
- Six-step first-launch tutorial; replayable from Settings.
- Analytics dashboard: answer count, accuracy, unique words practised, review-due count, seven-day activity and word performance.
- Smart review with per-word intervals and answer-based scheduling.
- New V1/V2 major-version archive chooser.
- Updated translations for English, Dutch, French and Spanish, including tutorial, analytics, version chooser and mindmap controls.

Learning analytics and smart-review history are stored locally in this browser/device. Study-set export currently exports the set, not the analytics/review history.

Install by extracting and merging into the repository root. Keep any other existing files and folders. Do not delete old releases.

V1.2 adds the latest-version launcher, V1.2 release entry, tutorial mode chooser, animated hands-off tour, text tutorial, written self-assessment practice, and updated placeholders.

V1.3 adds a selectable tutorial preference in Settings, a mascot-guided hands-on tutorial, a matching hands-off neon-highlight demo, and a complete text guide. The V2 archive now lists V1.3 and V1.2 in their chronological slots; the latest banner launches V1.3.

V1.4 adds the StudySonic racing-car mascot (mascot.png) and matching robotic pointer (pointer.png), uses them in the guided tutorial panel, and updates the latest-version launch and app version labels.

V1.4: full 28-step tutorial in Hands-on and Hands-off modes, complete long-form guide in EN/NL/FR/ES, settings replay, version hub tutorial entry, mascot.png and pointer.png. Analytics period and graph selectors added.

V1.4 bug-fix build:
- Removed the pointer artwork's opaque background and aligned its fingertip with the highlighted control.
- Moved the tutorial coach panel away from the main interaction area so it does not sit over the button being demonstrated.
- Hands-on guide now highlights both voice choices and the Type/Write practice selector; the Type path skips the paper-only step.
- Hands-off demo supplies sample words in the word-list field and adds them before advancing, instead of waiting on an empty form.
- Corrected Dutch tutorial wording to use “woord/woorden” for the items being entered.
- Analytics now recomputes the selected weekly, monthly or yearly period and renders actual bar, line or summary views.


V1.5 release: the fixed V1.4 application is now published as a distinct V1.5 version. V1.4 files remain intact and available in the archive. The latest-version launcher and V2 history now point to v15.html. This is a version-label/release fork; it does not claim additional feature changes beyond the fixed V1.4 build.
